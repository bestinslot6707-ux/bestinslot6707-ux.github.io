Ozon Automation Agent Test

Это личный инструмент владельца магазина для обслуживания его Google Таблиц и Google Apps Script, связанных с отчётами и процессами Ozon. Сервис не является продуктом Ozon и не предназначен для публичной регистрации.

Что делает инструмент

  • Считывает код Apps Script и ограниченные показатели из принадлежащих владельцу таблиц.
  • Предлагает небольшие изменения кода, проверяет их на отдельном тестовом проекте и сохраняет отчёт о результате.
  • При успешной проверке может обновить код основного Apps Script; бизнес-функции на основной таблице выполняются отдельно.

Доступ к Google

Доступ выдаётся владельцем через Google OAuth и используется локальным инструментом на его компьютере. Страницы этого сайта не запрашивают доступ к Google-аккаунту и не принимают данные таблиц.

Политика конфиденциальности

Личный проект владельца. Название Ozon используется только для обозначения подключаемого сервиса.
